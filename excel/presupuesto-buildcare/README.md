# Presupuesto BuildCare — Overleaf

## Cómo usar en Overleaf

1. Ve a [https://www.overleaf.com](https://www.overleaf.com) e inicia sesión.
2. Clic en **New Project** → **Upload Project**.
3. Sube la carpeta `presupuesto-buildcare` como ZIP, o sube solo `main.tex`.
4. Compilador: **pdfLaTeX** (por defecto).
5. Clic en **Recompile** → descarga el PDF.

## Compilar localmente

```bash
cd presupuesto-buildcare
pdflatex main.tex
pdflatex main.tex
```
